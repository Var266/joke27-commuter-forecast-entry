One-line weather forecast for a city that does not exist, for make.fun's "Charm the Commuter: Forecast a City That Isn't" bounty. The program writes a single original forecast (112 characters) to `/output/entry.txt`.

> Today in Gloomsbury, fog till 9am, 9°C: low visibility, high sighing, and your bus arriving in a bunch of three.

## Run it

```sh
node main.ts
```
